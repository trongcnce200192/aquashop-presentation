Introduction & Overview

The Problem

  • Manual record-keeping (paper-based).
  • Prone to human errors & data loss.
  • Time-consuming inventory checks.

Our Solution

A digitized inventory management system built with Java Console.

Key Benefits

  • Accurate tracking of fish imported/exported.
  • Flexible price updates.
  • Secure and permanent data storage.

System Architecture & UML

Click vào từng Class bên dưới để xem Source Code

Class FishManagement (Model)

  • Represents fish entities (ID, Name, Price, Quantity).
  • Applies Encapsulation: private attributes, accessed via getters/setters.

Class AquaShop (Controller)

  • Manages the core logic and operations.
  • Uses ArrayList<FishManagement> to store object data.
  • Handles user inputs via Scanner.

Core Features

CRUD Operations

  • Create: Add new fish.
  • Read: Display complete list.
  • Update: Adjust prices.
  • Delete: Remove from system.

Smart Search

Relative string matching. Supports case-insensitive keyword searches to easily find any fish model without remembering exact full names.

File I/O (Persistence)

  • Automatically loads past data from AquaShop.txt on application startup.
  • Saves all new changes permanently to disk upon exiting the program safely.

Technical Highlights & Error Handling

Data Validation & Crash Prevention

Uses Try-Catch blocks paired with while loops to continuously prompt users, preventing system crashes when they input text string instead of expected numerical values.

Strict Business Logic

  • No negative numbers
  • No duplicate IDs
  • No empty names allowed

UI Optimization (Console)

Leverages System.out.printf to format and align text strings into a beautiful data table. Automatically truncates extremely long fish names (appends "...") to prevent the console table layout from breaking apart.
