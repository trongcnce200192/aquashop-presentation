Introduction & Overview

The Problem

  • Manual record-keeping (paper-based).
  • Prone to human errors & data loss.
  • Time-consuming inventory checks.

Our Solution

A digitized inventory management system built with Java Console.

Key Benefits

  • Accurate tracking of fish imported/exported.
  • Flexible price updates.
  • Secure and permanent data storage.

System Architecture & UML

Click vào từng Class bên dưới để xem Source Code

Class FishManagement (Model)

  • Represents fish entities (ID, Name, Price, Quantity).
  • Applies Encapsulation: private attributes, accessed via getters/setters.

Class AquaShop (Controller)

  • Manages the core logic and operations.
  • Uses ArrayList<FishManagement> to store object data.
  • Handles user inputs via Scanner.

Core Features

CRUD Operations

  • Create: Add new fish.
  • Read: Display complete list.
  • Update: Adjust prices.
  • Delete: Remove from system.

Smart Search

Relative string matching. Supports case-insensitive keyword searches to easily find any fish model without exact names.

File I/O (Persistence)

  • Automatically loads data from AquaShop.txt on startup.
  • Saves all changes permanently upon exiting application.

Technical Highlights & Error Handling

Data Validation & Crash Prevention

Uses Try-Catch blocks & while loops to prevent system crashes when users input string text instead of numerical values.

Strict Business Logic

  • No negative price/quantity
  • No duplicate IDs
  • No empty names

UI Optimization (Console)

Uses System.out.printf to format string tables beautifully. Automatically truncates extremely long names (adds "...") to prevent console table layout from breaking.
